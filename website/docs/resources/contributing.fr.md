# Contribution et support

## Contributions

Nous serions ravis de recevoir toute forme de contribution.
Les pull requests sont idéales, mais les demandes de fonctionnalités, les signalements de bugs, etc. via les issues sont également les bienvenus.

Au minimum, **si vous appréciez nos outils et nos ressources, alors n'hésitez pas à nous attribuer une étoile sur GitHub et à montrer votre soutien !**

## Signalement de bugs

* Veuillez signaler tout bug que vous trouvez [ici.](https://github.com/Yamato-Security/wela/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
* Ce projet est actuellement activement maintenu, et nous serons heureux de corriger tout bug signalé.
