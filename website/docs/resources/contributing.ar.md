# المساهمة والدعم

## المساهمات

يسعدنا تلقي أي شكل من أشكال المساهمة.
طلبات السحب (Pull requests) هي الأفضل، لكن طلبات الميزات وإبلاغنا بالأخطاء وما إلى ذلك من خلال المشكلات (issues) مرحب بها أيضًا.

على أقل تقدير، **إذا أعجبتك أدواتنا ومواردنا، فيرجى منحنا نجمة على GitHub وإظهار دعمك!**

## إرسال الأخطاء

* يرجى إرسال أي أخطاء تجدها [هنا.](https://github.com/Yamato-Security/wela/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
* تتم صيانة هذا المشروع بنشاط حاليًا، ويسعدنا إصلاح أي أخطاء يتم الإبلاغ عنها.
