# Contribuições e Suporte

## Contribuições

Adoraríamos qualquer forma de contribuição.
Pull requests são as melhores, mas solicitações de funcionalidades, nos notificando sobre bugs, etc... por meio de issues também são muito bem-vindas.

No mínimo, **se você gosta das nossas ferramentas e recursos, então por favor nos dê uma estrela no GitHub e mostre seu apoio!**

## Envio de Bugs

* Por favor, envie quaisquer bugs que você encontrar [aqui.](https://github.com/Yamato-Security/wela/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
* Este projeto está atualmente sendo mantido ativamente, e ficamos felizes em corrigir quaisquer bugs reportados.
