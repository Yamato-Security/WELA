# การมีส่วนร่วมและการสนับสนุน

## การมีส่วนร่วม

เรายินดีรับการมีส่วนร่วมในทุกรูปแบบ
Pull request เป็นสิ่งที่ดีที่สุด แต่คำขอฟีเจอร์ การแจ้งบั๊กต่าง ๆ ผ่าน issue ก็เป็นที่ยินดีอย่างยิ่งเช่นกัน

อย่างน้อยที่สุด **หากคุณชื่นชอบเครื่องมือและทรัพยากรของเรา โปรดให้ดาวเราบน GitHub และแสดงการสนับสนุนของคุณ!**

## การส่งรายงานบั๊ก

* โปรดส่งบั๊กใด ๆ ที่คุณพบ [ที่นี่](https://github.com/Yamato-Security/wela/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D)
* โปรเจกต์นี้กำลังอยู่ในระหว่างการดูแลรักษาอย่างต่อเนื่อง และเรายินดีที่จะแก้ไขบั๊กใด ๆ ที่ได้รับรายงาน
