# 기여 및 지원

## 기여

어떤 형태의 기여라도 환영합니다.
풀 리퀘스트가 가장 좋지만, 이슈를 통해 버그 등을 알려주는 기능 요청도 매우 환영합니다.

적어도, **저희 도구와 리소스가 마음에 드신다면 GitHub에서 별표를 눌러 지지를 보여주세요!**

## 버그 제출

* 발견한 버그는 [여기에서](https://github.com/Yamato-Security/wela/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5Bbug%5D) 제출해 주세요.
* 이 프로젝트는 현재 활발히 유지 관리되고 있으며, 보고된 버그를 기꺼이 수정합니다.
